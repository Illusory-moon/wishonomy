# wishonomy —— 愿力经济（通用插件）

按**用户**记账的通用「愿力中心」：让 bot 自己按脾气收愿力、分愿力，粉丝可以送礼，
bot 攒到的愿力还能打给别人、换别人为它做一件事（欠条 = IOU）。

> 叫**愿力中心**而不是「账本」：bot 自己的笔记层已经叫账本了，两个东西撞名会把人绕晕 ✓

> 它**不是**给某一个角色写的。货币叫什么、礼物有哪些、给谁开，全在配置里。
> 通用插件里**不写**任何具体作品的名词、QQ 号、群号 —— 位置留给配置 ✓

---

## 它做什么

| 动作 | 语义 |
|---|---|
| **收愿力 / 分愿力** | bot 按自己的判断给某人记上一笔（`wish_mood`）。受单次上限与每人每日上限约束 |
| **送礼** | 粉丝把愿力交给 bot（`wish_gift`）。**单向奉献** —— 送了不代表 bot 欠他什么 |
| **查看** | 看某人的愿力 / 信誉分 / 最近流水（`wish_check`）—— 说不说、怎么说，由 bot 决定 |
| **对账** | 发行 / 送礼 / 支出 / 撤回 / 钱包数（`wish_audit`），给运营看，不是给群里念的 |
| **点单** | 用攒下的愿力换别人做一件事（`wish_grant`）—— **愿力立刻到账**，同时记一张欠条 |
| **判欠条** | 做了 / 没做 / 算了 / 撤回（`wish_iou_settle`）—— 守约涨信誉分、违约掉分、**愿力不退** |
| **看欠条** | 谁还欠着什么（`wish_ious`）|
| **信誉分** | 单独记一笔「这人说话算不算数」（`wish_credit`）—— 不是愿力，不花不转 |
| **排行** | 谁攒得多、谁最守约（`wish_leaderboard`）—— 她拿来念的 |

> **违约的处理方式**：不是"清空余额"，而是**信誉分**（决定下次还给他多少）+
> 她可以**撤回**那笔还没被动过的愿力（余额够就撤得回来，不够就撤不回来 —— 绝不扣成负数 ✓）

## 三条硬规矩（代码保证，不靠提示词）

1. **工具绝不返回 `None`** —— 有些框架把「工具返 None」当成「工具已直接发消息」⇒ 直接结束本轮 ⇒ 群里静悄悄。
   本插件的每个工具都经过兜底：**永远返回非空字符串**。
2. **愿力只能由工具改** —— 不提供任何「用户可直接调」的写入口；幂等键 `(kind, ref)` 防重复入账。
3. **bot 不能给自己加愿力** —— 工具层与中心层**双重**硬拦；它自己的愿力只能靠别人送礼进来。

### 护栏一览（都在配置里，改完**当轮生效**，不用重启）

| 护栏 | 默认 | 触发时 |
|---|---|---|
| 单次收/分愿力上限 | ±1000 | 拒绝并如实告诉她 |
| 每人每日净增上限（**按人，不按群**） | 3000 | 拒绝并告诉她"明天再给" |
| 全局日发行上限 | 50000 | **只记日志、不拦她**（拦数量级，不拦她的意志 ✓） |
| 送礼单人单日上限 | 3000 | 拒绝并告诉他"今天先这样" |
| 余额下限 | 0 | 花不起就失败（不自动借、不欠账） |

**备份**：`main.data_paths()` 给出要备份的文件清单（主库 + `-wal` + `-shm` 边车）——
部署侧的自动备份脚本按它挂上；**少备份一个边车文件 = 恢复时可能丢最后几笔** ✗

## 缓存纪律（用了提示缓存的部署必读）

愿力中心里有两种东西，**位置按"稳不稳"分开摆**（顺序反了会把整段历史缓存废掉 ⇒ 账单翻倍）：

| 内容 | 稳不稳 | 放哪 |
|---|---|---|
| 工具说明（docstring） | **永远不变** | 跟着工具定义走 = 稳定前缀 ✓ |
| 那一段说明文字（`INJECT_TAIL`） | **永远不变** | `system_prompt` 的**尾部** ✓ |
| 「他现在有多少愿力 / 信誉分」那一行 | **每轮可能变** | `extra_user_content_parts` 的**最后一个 part**（框架接在用户消息之后）✓ |

- 没有账户 ⇒ **一个字都不注入**（省 token 也省缓存）✓
- ❌ 不会把变动的数字写进 `system_prompt`（那会作废它后面的一切）
- 想完全不注入也行：配置里把 `inject_money` 关掉 ⇒ 只靠 `wish_check` 按需查
- 自检 **R23** 守着这几条（把变动内容塞进 `system_prompt` 会当场红 ✓）

## 安装

1. 把本仓库放进 AstrBot 的插件目录
2. 在插件配置里：`enabled` 打开、`enabled_self_ids` 填上**要用它的 bot**（不填 = 谁也不启用）
3. 按自己的世界观填 `money_name` 与 `gift_tiers`
4. 想让她每轮都知道对方有多少愿力 ⇒ `inject_money` 保持打开；想更省 token ⇒ 关掉（只按需查）

## 只读面板（给运营看的一页）

```bash
python panel.py                  # http://127.0.0.1:8765/（只绑本机 ✓）
python panel.py --port 9000      # 换端口
python panel.py --json           # 不开服务，直接吐 JSON（部署后核对用）
```

页面上有：当日发行/送礼/支出/撤回/账上总量 · 钱包一览 · 还没兑现的要求 ·
今天动得最多的人 · 最近流水（含**她写的原话**）。

三条纪律（**代码保证** ✓）：
1. **只读** —— 连接一律用 SQLite 的 `mode=ro` 打开，面板**写不了**库（连 WAL 都不碰 ✓）
2. **只绑 `127.0.0.1`** —— 默认不对外；要对外请自己套反代
3. **转义** —— 流水里的原话一律 `html.escape`（防 XSS ✓）

自检：`python panelcheck.py`（9 项，含真 HTTP 冒烟 / 只读保证 / 转义 / CLI 入口）

## 自检

```bash
python selfcheck.py     # 工具与账本：35 项
python panelcheck.py    # 只读面板：9 项
```

两个都**失败就 exit 1**；不依赖任何第三方库（只用标准库 + 临时目录里的真 SQLite 库）。
